# 毕业照档案馆

共同建设小学、初中、高中、中职与大学的班级影像档案：按学校、地区、教育阶段、毕业年份与班级浏览毕业照与校园照片。

## 技术栈

- **React 18** + **TypeScript** + **Vite**
- **React Router** 单页应用，响应式布局
- 无后端：档案、用户与上传内容保存在浏览器 **localStorage**（本机持久化）

## 数据与部署区域说明

MVP 不依赖云数据库或对象存储，**数据区域 = 用户浏览器所在设备**。预置示例学校与照片打包在前端静态资源中；用户注册、加入班级、上传照片仅写入本机。适合作为免费、零运维的演示与原型；若日后接入真实后端，建议将业务数据部署在目标用户主要所在区域（例如中国大陆用户可选用国内云存储 + RDS），并单独做隐私合规评估。

## 功能概览

| 功能 | 说明 |
|------|------|
| 浏览与筛选 | 学校、省份/城市、教育阶段、届别、班级名 |
| 学校主页 | 学校介绍、下属班级、公开影像 |
| 班级档案 | 班级信息、加入/退出、上传入口 |
| 照片详情 | 大图、元数据、上传者可改隐私/删除 |
| 模拟注册登录 | 默认以「访客体验」模拟已登录；仍可注册/登录真实本机账号（SHA-256 摘要，非生产级安全） |
| 隐私范围 | 公开 / 仅班级成员 / 仅自己 |
| 示例数据 | 覆盖五类教育阶段的多校多班虚构档案 |

## 模拟服务与限制

- **影像**：预置图为内联 SVG 渐变占位，不调用外部图床。
- **登录**：无真实认证服务；不使用 `NETO_ADMIN_*` 环境变量（本产品为面向所有人的自助注册，无独立管理员后台）。
- **上传**：图片以 Base64 存入 localStorage，单张建议小于 **800KB**，否则可能触达浏览器配额上限。

## 使用提示

1. 打开首页浏览预置学校与班级。
2. 注册账号 → 进入班级页 → **加入班级档案** → **上传照片**。
3. 在照片详情页（本人上传）可调整隐私或删除。
4. **我的班级** 查看已加入班级与上传记录。

清除浏览器站点数据将重置用户账号与上传内容，预置示例档案会在下次加载时自动恢复。
